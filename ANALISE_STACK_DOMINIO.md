```
1. Acesse: https://registro.br
2. Campo de busca: digite o domínio
3. Clique em "Buscar"
4. Resultado:
   - "Disponível para registro" = ✅ LIVRE
   - Mostra titular = ❌ REGISTRADO
```

**Opção 2: Whois via Web**
```
Site: https://rdap.registro.br/domain/DOMINIO.com.br

Exemplo: https://rdap.registro.br/domain/scoutfutebol.com.br

Resultado:
- HTTP 404 = ✅ DISPONÍVEL
- HTTP 200 + JSON = ❌ REGISTRADO
```

**Opção 3: Terminal (se whois funcionar)**
```bash
whois -h whois.registro.br scoutfutebol.com.br

# Se retornar "No match" = DISPONÍVEL
# Se retornar dados do owner = REGISTRADO
```
